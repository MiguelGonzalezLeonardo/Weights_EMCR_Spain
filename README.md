This repository contains datasets with weights to make the new Spanish Migration and Change of Residence Statistics consistent with the previous migration sources, Residential Variation Statistics and Migration Statistics.

Weights were calculated for internal and international migration (outflows and inflows) at the NUTS 2 and NUTS 3 Eurostat levels. Weights for migrations at country level are also included.

There are 2 different datasets for NUTS 2 and NUTS 3 regions. Calculations are included in the datasets.

Please see the file Data_descriptor.xlsx for further details.
